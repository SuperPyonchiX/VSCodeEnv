# スキル一覧

## 利用可能なスキル

### python-mcp-development
**目的**: Python MCPサーバーの開発支援

**提供リソース**:
- FastMCPサーバーテンプレート
- pyproject.toml設定
- テストコード例

**使用場面**:
- 新規MCPサーバーの作成
- ツール・リソース・プロンプトの実装
- STDIO/HTTPトランスポートの設定

### typescript-mcp-development
**目的**: TypeScript MCPサーバーの開発支援

**提供リソース**:
- MCP SDKサーバーテンプレート
- package.json、tsconfig.json設定
- zodスキーマ定義例

**使用場面**:
- Node.js環境でのMCPサーバー作成
- Express統合
- 型安全なスキーマ定義

### cpp14-code-review
**目的**: AUTOSAR C++14準拠のコードレビュー

**提供リソース**:
- Clang-Tidy設定ファイル
- GitHub Actions CI設定
- レビューチェックリスト

**使用場面**:
- 安全性重視のC++コードレビュー
- 静的解析ツールの設定
- CI/CDパイプラインの構築

### markdown-documentation
**目的**: Markdown形式の技術文書作成

**提供リソース**:
- 6種類のテンプレート（説明資料、手順書、提案書、報告書、FAQ、会議議事録）
- Mermaid図解リファレンス
- サンプル文書

**使用場面**:
- プロジェクトドキュメント作成
- 技術仕様書の執筆
- 会議記録の整理

## スキルの呼び出し方

### CLINEでの使用
プロジェクトルートで作業中、関連するタスクを依頼すると自動的にスキルが適用される。

### 明示的な指示例
- 「Python MCPサーバーを作成して」
- 「このC++コードをAUTOSAR C++14規約でレビューして」
- 「手順書をMarkdownで作成して」
